FAQ

The honest answers

Is the free edition complete?

Yes — it is the product, single-user, not a trial. Cloud sells review, identity, the clock and custody, never the mechanism.

What if my site is Vue or Svelte?

The standalone and Cloud dashboards work with any host via the preview-URL primitive. What you hand-wrap is the embedded-component layer; stet scan's shapes are JSX, so template copy is adopted by register.

What about copy that already lives in a CMS?

stet import takes any JSON/CSV export through one mapping file. Per-CMS recipes, no connectors.

Can I leave?

The repo always holds a complete, buildable copy of every string; contacts export as CSV/JSON and never enter git. The eject promise is a public page.
